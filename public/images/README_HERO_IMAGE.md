# Hero Background Image

## Image Requirements

Place your hero background image in this directory with the filename: `hero-background.jpg`

### Recommended Specifications

- **Format**: JPG (optimised) or WebP (for better compression)
- **Dimensions**: Minimum 1920px width × 1080px height (or higher for retina displays)
- **Aspect Ratio**: 16:9 or wider
- **File Size**: Optimised to under 500KB for fast loading
- **Style**: 
  - Serene, natural setting (e.g., forest path, peaceful landscape)
  - Dark enough to provide contrast for white text
  - Professional and calming aesthetic
  - High quality, not pixelated

### Image Optimisation

Before uploading, optimise your image using:
- [TinyPNG](https://tinypng.com/) - Compress JPG/PNG files
- [Squoosh](https://squoosh.app/) - Advanced image compression
- [ImageOptim](https://imageoptim.com/) - Mac app for batch optimisation

### Alternative Formats

If you want to use WebP format (better compression), update the CSS:
```css
background-image: url('/images/hero-background.webp');
```

### Fallback

If no image is provided, the hero section will display a dark gradient background as a fallback.

### Example Image Sources

- Unsplash: Search for "forest path", "nature trail", "serene landscape"
- Pexels: Free stock photos
- Pixabay: Free images

Make sure you have the rights to use the image commercially.
