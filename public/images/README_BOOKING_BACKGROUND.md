# Booking Background Image

## Image Requirements

Please add a background image for the booking form section at:

**Path:** `/public/images/booking-background.jpg`

## Image Specifications

- **Recommended Size:** 1920x1080px or larger
- **Format:** JPG or WebP
- **Content:** A supportive, calming image showing connection or support (e.g., two people holding hands, a supportive gesture, or a calming therapy setting)
- **Style:** Should be suitable for blurring - the image will be blurred in the design
- **Optimization:** Compress the image before adding (use tools like TinyPNG)

## Usage

This image will be used as a blurred background for the booking form section, creating a professional and calming aesthetic that matches the therapy/counselling theme.

## Current Fallback

If the image is not present, the section will still function but without the background image effect.
