# Profile Photo

## Image Requirements

Place your profile photo in this directory with the filename: `profile-photo.jpg`

### Recommended Specifications

- **Format**: JPG (optimised) or WebP
- **Dimensions**: Minimum 800px width × 1000px height (portrait orientation)
- **Aspect Ratio**: 3:4 (portrait)
- **File Size**: Optimised to under 300KB for fast loading
- **Style**: 
  - Professional portrait photo
  - Clean, neutral background (light cream or white)
  - Good lighting, clear and professional
  - High quality, sharp focus
  - Professional attire
  - Friendly, approachable expression

### Image Optimisation

Before uploading, optimise your image using:
- [TinyPNG](https://tinypng.com/) - Compress JPG/PNG files
- [Squoosh](https://squoosh.app/) - Advanced image compression
- [ImageOptim](https://imageoptim.com/) - Mac app for batch optimisation

### Alternative Formats

If you want to use WebP format (better compression), update the image src in `src/pages/index.jsx`:
```jsx
<img src="/images/profile-photo.webp" alt="Counsellor" />
```

### Styling Notes

The image will be displayed in:
- A white card with rounded corners
- Shadow effect for depth
- Responsive sizing (stacks on mobile)
- Maintains 3:4 aspect ratio

### Example Image Sources

- Professional photographer portrait session
- High-quality self-portrait with good lighting
- Stock photo service (ensure commercial license)

Make sure you have the rights to use the image commercially.
